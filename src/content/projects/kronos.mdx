problem: A small business wants to expand, but deciding on intuition alone leaves out the initial investment, the new salaries and running costs, and the time it takes for the new capacity to fill. Kronos gathers those numbers, projects them over time and returns the indicators needed to decide whether the investment pays off.
decisions:
  - title: The economic model is pure functions
    body: NPV, IRR, payback, break-even and the scenarios are plain functions that take a case and return numbers. The model imports only types, never React, so the interface calls it and nothing flows back.
  - title: Tested where the money is
    body: 31 Vitest tests load a real case and check that every indicator matches the documented economic model, without a browser.
  - title: No backend on purpose
    body: The case lives in the browser's localStorage and can be saved to or opened from a .json file. With no server or database, the tool is free to deploy and easy to carry from one machine to another.
  - title: localStorage as an external store
    body: The case is read through useSyncExternalStore with a separate server snapshot, so the server render and hydration agree and no effect is needed to load saved data.
